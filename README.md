# 钙钛矿文献

在浏览器里按材料体系、研究主题和年份浏览钙钛矿光伏文献。交叉图以篇数统计，点击有数据的格子可查看对应的文献。

## 使用

用浏览器打开 `index.html`。初次打开会加载合成演示数据。下载 CSV 模板，每行填写一篇文献，再导入工具。标题必填，年份、材料体系、研究主题、DOI 和备注可留空。导入的文献可在详情中补填 DOI。

也可点击“按 DOI 查文献”，从 Crossref 或 DataCite 获取公开题名、作者、年份和出版来源。核对后可加入列表，并选填材料体系和研究主题。已有条目可从详情中查询和更新元数据。点击 DOI 可前往出版方页面。

导入和编辑在当前浏览器页面处理。刷新前可导出 CSV 保存数据，下次打开时重新导入。

## GitHub Pages

将此目录的文件放入独立仓库的根目录，在 Settings → Pages 选择 Deploy from a branch，来源设为 `main` 分支的 `/(root)`。站点入口为 `index.html`，可作为单文件编辑，无需依赖安装或构建。
